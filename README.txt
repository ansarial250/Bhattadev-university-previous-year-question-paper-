# Bhattadev University Question Paper Portal

Open `index.html` in a browser to test the website.

Important:
- The included upload feature stores PDFs only in the current browser using localStorage.
- It does NOT make uploaded PDFs available to other students.
- For a real public website, connect the upload/admin section to a backend and online file storage/database.

Deploy the front end online and add a secure admin login + cloud PDF storage/database.
